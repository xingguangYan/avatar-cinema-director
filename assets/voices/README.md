# Voice Pack

This directory contains:

- `kokoro/`: 54 offline Kokoro voice embeddings.
- `edge-voices.raw.json`: the complete Edge TTS voice catalog returned by the
  local `edge-tts` client.
- `catalog.json`: normalized catalog for both engines.
- `samples/`: local preview files generated by `scripts/voice_pack.py`.

The Edge preview MP3 files are intended as local audition samples and are not
committed to the public repository. Regenerate them with:

```powershell
& $env:TALKING_VIDEO_AUDIO_PYTHON scripts/voice_pack.py --samples
```

Use `--force-samples` to replace existing samples.

## Kokoro

Kokoro voices are offline `.pt` embeddings and are selected with
`"engine": "kokoro"` in the character manifest.

Source:

https://huggingface.co/hexgrad/Kokoro-82M

## Edge TTS

Edge voices are online Microsoft neural voices. The catalog covers 322 voices
and 75 language families in the generated snapshot.

Use:

```json
{
  "engine": "edge",
  "voice": "zh-CN-XiaoxiaoNeural"
}
```

Edge TTS is an online service. Availability and usage are subject to Microsoft
terms and the current `edge-tts` client behavior.
